Requirements

  • Paper 1.21.11 or newer.
  • Java 21.
  • The current CoreExtractionX-2026.1.1.jar from Modrinth.

Download

Modrinth is the public download source. The current 2026.1.1 file is classified as beta; validate it on a staging world before production use.

Installation

  1. Stop the Paper server.
  2. Back up an existing plugins/CoreExtractionX/ folder.
  3. Place the JAR in the server plugins/ directory.
  4. Start once and inspect the console for config errors and loaded/skipped rule counts.

Generated files

plugins/CoreExtractionX/
  config.yml
  ores.yml
  messages.yml

First tests

  1. Mine normal coal ore without Silk Touch and confirm the configured cobblestone replacement.
  2. Mine a deepslate ore and confirm cobbled deepslate.
  3. Mine Nether quartz ore and confirm netherrack.
  4. Test Silk Touch; the bundled VANILLA policy should bypass extraction.
  5. Temporarily add one DROP rule and test a fixed amount.
  6. Use a non-op player and a protected region before enabling broad rules.

Validation boundary

The plugin logs a warning rather than hard-disabling itself solely because the reported Minecraft version is older than 1.21.11. Treat 1.21.11+ as the supported target.

Normal reload

Use /coreextractionx reload or /cex reload after edits to config.yml, ores.yml or messages.yml. The success message reports loaded and skipped rule counts.

Safe-disabled recovery

An invalid global enum in no-permission behavior, Silk Touch behavior, world-filter mode or drop-spawn mode safe-disables extraction. The command remains registered: fix the value and reload. Invalid enabled block rules are skipped individually and do not disable valid rules.

Restart required

  • Replacing the JAR.
  • Changing Paper/Minecraft version.
  • Validating a clean boot after major operational changes.

Backup

Copy all three YAML files before a large ruleset edit. There is no database or data migration, but an incorrect rule can materially change mined blocks, drops, XP and tool durability.

Purpose

config.yml controls global enablement, permissions, fallbacks, world scope, manual drop location, replacement physics and XP preservation.

Current bundled default

Identity and enable state

  • config-version: bundled marker only; current Java source does not read it.
  • settings.enabled: master extraction switch. Commands remain available when false.
  • settings.debug: currently logs that debug mode is enabled; no additional debug path was found.

Permission and Silk Touch

  • settings.permission: global required permission when a rule has no nonblank override. Blank means no permission required.
  • settings.no-permission-behavior: VANILLA bypasses CoreExtractionX; DENY cancels and sends no-permission.
  • settings.silk-touch-behavior: VANILLA bypasses CoreExtractionX; DENY cancels and sends silk-touch-denied. A rule may override this value.

World filter

  • world-filter.mode: DISABLED, WHITELIST or BLACKLIST.
  • world-filter.worlds: case-insensitive world-name list. An empty WHITELIST runs nowhere and logs a warning; an empty BLACKLIST blocks nothing.

Manual drop spawn

  • drop-spawn.mode: HIT_FACE or BLOCK_CENTER.
  • drop-spawn.raytrace-distance: maximum face trace distance, clamped to at least 0.1.
  • drop-spawn.face-offset: distance from center toward the hit face, clamped to at least 0.

HIT_FACE falls back to block center when the trace is missing, has no face or hits a different block.

Replacement and experience

  • replacement.apply-physics: passed to the replacement block update. False avoids unrelated physics by default.
  • experience.preserve-vanilla-exp: in REPLACEMENT, respawn the XP captured from the cancelled original break. It does not affect DROP mode.

Fatal global enum errors

Invalid no-permission, Silk Touch, world-filter or drop-spawn enum text safe-disables all extraction. Fix the value and reload; commands remain usable.

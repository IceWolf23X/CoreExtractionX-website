Purpose

ores.yml defines dynamic source-block rules. Every direct child of blocks is interpreted as a case-insensitive Bukkit/Paper material name.

Current bundled default

Complete rule schema

Path under blocks.<source>Semantics
enabledRequired boolean. False skips the rule before source/mode/material validation.
modeREPLACEMENT or DROP.
replacementNon-air block different from source in REPLACEMENT; non-air item in DROP.
permissionOptional nonblank rule-level permission; overrides the global permission.
silk-touch-behaviorOptional VANILLA or DENY; overrides the global value.
drop.*DROP-only amount schema. Ignored in REPLACEMENT.

Material validation

  • The source must exist and be a block.
  • REPLACEMENT target must exist, be a block, not be AIR and not equal the source. Same-source replacement is rejected to prevent repeated extraction.
  • DROP target must exist, be an item and not be AIR.
  • An invalid enabled rule is skipped with a warning; valid rules continue loading.

DROP amount schema

  • drop.amount-mode: FIXED, RANDOM, MATCH_DROPS or MATCH_QUANTITY. Missing DROP section defaults to FIXED 1.
  • drop.fixed-amount: FIXED only; must be at least 1.
  • drop.min-amount: RANDOM only; may be 0.
  • drop.max-amount: RANDOM only; must be at least 1 and not below min.
  • drop.fortune-multiplier: RANDOM only; multiply the sampled base by max(1, fortuneLevel + 1).
  • drop.max-final-amount: RANDOM only; 0 means no cap, otherwise cap the multiplied amount. Negative values invalidate the rule.

MATCH_DROPS uses initial quantity captured at LOWEST. MATCH_QUANTITY uses current quantity at the HIGHEST handler and can reflect earlier plugin changes. Both match total item quantity, not the quantity of one material.

Bundled rules

The disabled stone entry is a template. Nineteen rules are enabled: eight normal overworld ores become cobblestone, eight deepslate ores become cobbled deepslate, Nether quartz and gold ores become netherrack, and Ancient Debris becomes blackstone.

Safe custom-rule process

  1. Copy the disabled template and rename the source key.
  2. Choose mode and a compatible replacement.
  3. Validate optional permission, Silk Touch and DROP settings.
  4. Keep enabled: false until values are complete.
  5. Enable, reload and check loaded/skipped counts plus console warnings.
  6. Test normal, Fortune, Silk Touch and wrong tools in a staging world.

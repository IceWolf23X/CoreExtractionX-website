Declared permissions

  • coreextractionx.reload: default op.
  • coreextractionx.use: default true; also the bundled global extraction permission.

Runtime permission resolution

  1. Use a nonblank blocks.<source>.permission if present.
  2. Otherwise use settings.permission.
  3. If the resolved text is blank, require no permission.
  4. If the player lacks the permission, apply settings.no-permission-behavior.

Custom per-rule strings are supported but are not predefined declared nodes. Configure them through the server's permission manager.

Production validation checklist

  • Back up config.yml, ores.yml and messages.yml.
  • Boot Java 21 and supported Paper without load errors.
  • Run /cex reload; verify loaded/skipped counts and every warning.
  • Mine one normal, one deepslate and one Nether default rule.
  • Test Ancient Debris if it is enabled in the server's policy.
  • Test a custom REPLACEMENT rule with correct, wrong, Fortune and Silk Touch tools.
  • Test DROP with FIXED, RANDOM, MATCH_DROPS and MATCH_QUANTITY where used.
  • Verify RANDOM multiplier and cap boundaries.
  • Test HIT_FACE fallback and BLOCK_CENTER.
  • Test a non-op player with global permission, per-rule override, VANILLA fallback and DENY fallback.
  • Test DISABLED, WHITELIST and BLACKLIST world filters, including an empty whitelist.
  • Test replacement.apply-physics only where surrounding updates are understood.
  • Verify XP preservation on and off in REPLACEMENT.
  • Test every protection/custom-drop plugin that changes break or drop events and confirm event ordering.
  • Restart once after replacing the JAR and repeat one representative rule.

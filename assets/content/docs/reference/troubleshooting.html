No files generated

  • Confirm the JAR is in the Paper plugins/ directory.
  • Confirm Java 21 and a supported Paper 1.21.11+ build.
  • Inspect plugin-load errors before editing YAML.

Command works but extraction is disabled

Look for a fatal invalid enum in no-permission behavior, Silk Touch behavior, world-filter mode or drop-spawn mode. Fix it and reload. Also confirm settings.enabled: true.

A rule does nothing

  • Confirm the source key is a block material and enabled is a real boolean set to true.
  • Confirm SURVIVAL mode and an allowed world.
  • Check effective permission and Silk Touch policy.
  • Read the exact skipped-rule warning.

A rule is skipped

REPLACEMENT needs a different non-air block target. DROP needs a non-air item target and valid amount settings. Invalid enabled rules do not block valid rules.

Block breaks but no replacement appears

Confirm REPLACEMENT mode, allowed scope and that no earlier plugin cancelled the break. DROP mode intentionally lets the source disappear normally.

Silk Touch bypasses extraction

This is correct for the bundled VANILLA policy. Use DENY globally or on that rule only when the break should be cancelled.

Drops spawn in an unexpected spot

Use BLOCK_CENTER for fixed center spawning. HIT_FACE falls back to center when the ray trace does not match the source block face.

Drops appear in the wrong amount

Check the amount mode. MATCH_DROPS uses LOWEST initial quantity; MATCH_QUANTITY uses HIGHEST current quantity. Both total all event item stacks. RANDOM may multiply by Fortune and then apply a positive cap.

Reload failed

Fix YAML syntax/indentation, then fatal global enums. Reload again and compare loaded/skipped counts with the intended enabled rules.

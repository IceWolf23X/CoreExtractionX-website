Metadata and runtime notes

  • config-version is bundled but not read by current Java source.
  • settings.debug logs enablement but does not activate another observed debug behavior.
  • The runtime version check warns below 1.21.11 rather than disabling the plugin.
  • Modrinth metadata currently lists earlier 1.21 versions, while the verified supported target and build API are 1.21.11+.

Verification limits

Source inspection and unit tests describe core parsing, amount, permission, stack-splitting and pending-drop contracts. A server owner must still validate real event ordering, protection plugins, tools, drops and world behavior on the exact Paper build used in production.

CoreExtractionX is a focused Paper survival plugin for configured block extraction. A rule can replace the mined block while preserving its natural drops, or leave vanilla breaking intact and add a configured extra item.

Version 2026.1.1 targets Java 21 and Paper 1.21.11 or newer. It uses three public YAML files and requires no database, economy, GUI, proxy or client module.

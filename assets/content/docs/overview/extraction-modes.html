REPLACEMENT mode

  1. Read natural drops once from the source block using the current main-hand tool and player.
  2. Capture the experience amount from BlockBreakEvent.
  3. Suppress vanilla item drops and cancel the original break.
  4. Set the configured replacement block with the configured physics flag.
  5. Damage the main-hand tool once.
  6. Spawn the previously calculated natural drops at the configured location.
  7. If enabled, spawn the captured XP as an orb.

There is no separate correct-tool gate. With a tool that produces no natural drops, the source can still be replaced and yield no item. Test wrong-tool behavior for every valuable rule.

DROP mode

The break remains vanilla. At block-break time CoreExtractionX records the player, block position, source material, rule, drop location and Fortune level. During BlockDropItemEvent it captures the initial item quantity at LOWEST, then removes the pending context and adds the configured item at HIGHEST.

The pending context is removed after handling or on the next scheduler tick. If no matching drop event arrives, no extra item is spawned.

DROP amount modes

  • FIXED: exactly fixed-amount.
  • RANDOM: inclusive min/max; optional multiplication by max(1, Fortune + 1); optional positive cap.
  • MATCH_DROPS: total generated item quantity seen at LOWEST, before later event changes.
  • MATCH_QUANTITY: total current event item quantity when CoreExtractionX handles HIGHEST; earlier plugin modifications can affect it.

The configured extra material is split into legal stacks using that material's maximum stack size.

Experience and durability

REPLACEMENT must handle durability and optional XP because it cancels the original event. DROP leaves the original break, tool damage, original drops and XP to vanilla/Paper and adds only the extra item.

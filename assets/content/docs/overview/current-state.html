Platform and Java

  • Java 21.
  • Paper API target 1.21.11-R0.1-SNAPSHOT.
  • Standalone Paper server; Modrinth also labels the project for Purpur.
  • No Spigot, Velocity, Bungee, Fabric or client module.

Runtime version check

The plugin warns when the reported Minecraft version is older than 1.21.11, but the current source does not disable itself through a hard runtime guard. The supported target remains Paper 1.21.11+; do not treat a warning-only startup on an older server as compatibility evidence.

Dependencies and integrations

Paper API is the only declared runtime API and is provided by the server. Vault, PlaceholderAPI, WorldGuard, GriefPrevention, an economy, a database and a resource pack are not required. Protection compatibility comes from event cancellation rather than a plugin-specific hook.

Anonymous bStats reporting uses project ID 33072. Server owners control metrics globally in plugins/bStats/config.yml.

Release maturity

The current source and newest Modrinth file are both 2026.1.1. Modrinth classifies that file as beta.

Deliberate exclusions

CoreExtractionX does not implement vein mining, auto mining, a custom progression system, economy rewards, a GUI, persistent player state or a general-purpose custom-drop framework.
